# Referencia: matices y ejemplos

## Criterios para elegir tipo de salida

| Señal en el insumo | Preferencia |
|--------------------|-------------|
| Objetivos medibles, usuarios, integraciones nombradas, restricciones claras | Propuesta de valor / comercial + riesgos |
| "Queremos algo como…", sin flujos ni datos definidos | Guía para ventas y próxima reunión |
| Mezcla de definido + vacío | Documento mixto |

## Ejemplo de preguntas para guía de ventas (adaptar al dominio)

- ¿Quién opera el proceso hoy y qué herramientas toca en un día típico?
- ¿Qué datos existen en fuente de verdad y en qué formato están disponibles?
- ¿Hay ventanas de migración o cortes (fin de mes, cierre contable, campañas)?
- ¿Compliance (datos personales, retención, auditoría) aplicable?
